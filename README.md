# 屍城日誌 ZOMIBEE

喪屍末日回合制生存網頁遊戲。系統參考 XIFM 傳奇十一人嘅抽卡。

- **廣播招募（抽卡）**：82 個角色，等級 UR / SSR / SR / R / C。UR 係傳奇人物（呂布、孫悟空、雷神索爾、達文西、鬼新娘、陳墨、柳如烟、梅林），極強但唔識煮飯、維修，食量 ×2，三個以上同場會互相唔服；呂布有反骨（有貂蟬就唔會背叛）。單抽 100 電池、10 連 900（保證 SR 以上），50 抽保底 SSR，重複角色突破 +1★（全能力 +1）
- **每個人都有用**：7 項數值（力量、敏捷、感知、技術、醫術、廚藝、意志）決定佢擅長邊份工，卡上用 S–D 顯示；另有專長同特質（例如狙擊手唔使彈藥、廚師慳食物、唐狗巡邏 +40%）。貓狗唔識講嘢，亦唔會做煮飯、維修、醫療
- **工作**：搜括、巡邏、保安、維修、煮飯、醫療、休息
- **狀態**：HP、體力、意志；受傷、重傷、感染（三日屍變，約 5% 機會唔變，反而變成變種人：狂暴型、疾行型、感應型或再生型，數值改變、對病毒免疫、食量 ×1.5）、發燒、肚餓、疲勞、恐慌、振奮，全部影響效率同決策
- **日夜結算**：白天工作 → 晚飯 → 夜晚屍潮對防禦（圍牆 + 保安 + 彈藥）
- **據點平面圖**：開局揀街口便利店、舊商場或者唐樓天台。每個據點有自己嘅區域（例如便利店：捲閘＝保安、微波爐櫃位＝煮飯、倉底＝維修），每個人會企喺佢負責嘅區域；直接拖人去另一個區域就調工（亦可以撳人再撳區域）。據點頁一版睇晒：章節同今晚預報一行、搜括地點同維修項目一行、平面圖頂顯示床位圍牆設施等數值、陣營加成喺地圖下面
- **清場搬遷**：搜括會累積該地點嘅清場進度，100% 之後可以搬過去。街市、屋邨、五金舖、診所、警署、地鐵站、中學、軍營、研究所各有唔同床位、圍牆同每日產出
- **S 級能力**：某份工評級係 S 嘅人，做嗰份工時會觸發專屬能力（滿載而歸、掃蕩、一夫當關、巧手、盛宴、妙手回春）
- **人物圖**：每個角色有自己嘅外形（髮型、膚色、制服、配件），貓狗畫成動物；喺平面圖會按工作做動作（揸武器守閘、拎鍋煮飯、拎急救箱、坐低休息），受傷包頭、感染變青、重傷瞓低
- **浮窗**：喺平面圖撳人，旁邊即刻彈出數值、狀態、工作評級同裝備
- **裝備**：武器、防具、道具三格，19 款裝備（棒球棍、武士刀、狙擊步槍、防暴盾、消防衣、登山背包、急救包、大鐵鑊等），搜括、空投、行商可以搵到。力量唔夠重量會打折兼多耗體力，體力低時重裝備效果減，專精角色用效果 ×1.5
- **陣營**：港灣街坊、寶島、神州、和風、韓流、西方、軍警消防、醫者仁心、食神、宗教、毛孩、三國、北歐神話、西遊、東方鬼話、修仙、魔幻、文藝復興。同陣營兩人以上喺據點全工作有加成，同陣營做同一份工再加
- **副本**：抽到特定陣營角色會解鎖副本——三國本「虎牢關」、神話本「諸神黃昏」、西遊本「火焰山」、鬼故事本「蘭若寺」、修仙本「萬魔窟」、魔幻本「阿瓦隆迷霧」、文藝復興本「米蘭密室」。對應陣營去有加成，普通人去受傷風險高兼跌意志（例如修女、道士去蘭若寺有加成）。完成副本攞專屬裝備
- **裝備抽獎（物資空投）**：裝備分 UR–C，空投係主要來源；UR 係傳奇角色專屬裝備，集齊一套會覺醒套裝技能（例如呂布「人中呂布」、索爾「諸神黃昏」、鬼新娘「冥婚」）。搜括、行商、完成章節同副本都會有裝備
- **據點要齊人**：冇人維修圍牆會自然損耗，冇人巡邏屍潮 +10%，冇人煮飯意志大跌
- **分部**：據點住唔晒，後備人員可以派去已清場嘅地點或者舊據點設立分部。電腦每日自動按能力分工、搜括、守夜，將剩餘物資運返主據點（缺嘅由主據點補給）。分部有忠誠度，會有聯合守夜、交易、求援、聯合突襲、叛變等突發事項
- **換位**：撳後備人員可以同據點入面任何人換床位同工作；貓狗唔佔床位
- **設施**：圍牆、床位、廚房、醫務室、雨水收集、天台菜園、無線電台
- **十三章劇情**（完成本章目標先解鎖下一章，每章最少 4 日、最多 12 日）：港產爆發 → 韓式南下列車 → 日式學園默示錄 → 朝鮮古疫「生死草」 → 國產網文喪屍進化（晶核） → 美式人禍 → 西方藥廠解藥 → 大陸末日文：末日列車 → 地洞 → 監獄風雲 → 喪屍醫院 → 屍王地宮 → 末日堡壘
- **決策事件**：被咬點處理（血清／截肢／隔離／了斷）、崩潰、爭執、行商、空投等 20 多個
- **章節禮物**：每完成一章目標，額外送 900 電池（一次十連）
- **成就獎章**：30 個獎章（擊殺數、生存日數、人數、圖鑑、套裝、副本、搬遷、設施、變種人、解藥、屍王等），自動頒發電池、物資、裝備
- **致敬劇本**：部分獎章解鎖原創劇本，風格致敬經典遊戲同電影——義莊驚魂（港產殭屍片風）、洋館驚魂（生化恐怖風）、地獄魔窟（暗黑刷寶風）、霧鎮（心理恐怖風）、孢子城（末日求生風）、末日公路（公路廢土風），各有陣營加成同專屬裝備
- **結局**：喺末日堡壘撐過屍潮之夜
